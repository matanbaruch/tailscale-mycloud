Tailscale for WD My Cloud EX2 Ultra

A web-installable Tailscale app for the Western Digital My Cloud EX2 Ultra (OS 5).

⬇ Download the latest .bin View on GitHub

What it does

Connects your NAS to your Tailscale tailnet, installed the normal WD way — upload a .bin from Apps → Install Manually — then managed from a page right inside the dashboard: paste an auth key, connect/disconnect, and flip capability toggles. Your node identity is stored on the persistent data volume, so it survives reboots and you only enter a key once.

Install

  1. Download MyCloudEX2Ultra_tailscale_<version>.bin from the latest release.
  2. My Cloud dashboard → Apps → Install an app manually → pick the .bin (see WD's OS5 guide).
  3. Open Apps → Tailscale, paste an auth key from login.tailscale.com → Keys, choose toggles, click Connect.
  4. Reach the NAS at its 100.x.y.z address from any tailnet device.

Build from source

Requires Docker (the WD packaging tool is a Linux binary run inside the build image).

git clone https://github.com/matanbaruch/tailscale-mycloud
cd tailscale-mycloud
./build.sh
# -> packages/MyCloudEX2Ultra_tailscale_<version>.bin

The bundled Tailscale version is auto-bumped daily via a scheduled PR; merging it cuts a new release.

Honest status

The package is built and round-trip-verified in CI (correct APKG header, armhf tailscaled, expected files), but the maintainer can't execute it on physical NAS hardware in CI. If TUN is unavailable on stock OS5, the app falls back to userspace networking and warns you in the status panel. See the troubleshooting guide.
